# 👟 Shoe Vault – Shoe Store POS

Shoe Vault is a Python-based online shoe store and Point of Sale (POS) system built with **Streamlit**.

It provides a complete shoe-shopping experience with product browsing, shopping cart, VIP billing, PDF invoice generation, payment-method selection, and store dashboard.

## ✨ Features

- 👟 100 shoes automatically generated
- 💰 Automatic product pricing
- 🔎 Shoe search
- 🏷️ Brand filtering
- 👨 Men's and 👩 Women's categories
- 🛒 Shopping cart
- 📦 Stock information
- 🧾 VIP billing system
- 💸 Discount calculation
- 🧮 Tax calculation
- 💳 Payment Center
- 📱 JazzCash payment option
- 📱 Easypaisa payment option
- 🏦 Bank Transfer option
- 💵 Cash payment
- 💳 Card / Online Payment option
- 📄 Professional PDF invoice
- 📊 Store dashboard
- 🐍 Built with Python
- 🌐 Deployable on Streamlit

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- ReportLab
